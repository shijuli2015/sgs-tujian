# 三国杀 DIY 武将图鉴

在线访问：**https://shijuli2015.github.io/sgs-tujian/**

一个开源、纯静态的三国杀 DIY 武将技能查询网站。把 [sgsshap](http://www.sgsshap.cn) 导出的武将卡（`.json` + 同名 `.png`）放进一个文件夹，运行一条命令就能生成完整网站，可以直接部署到 GitHub Pages、Vercel 或任何静态托管。

版式参考了 [sanguosha-tujian](https://sanguosha-tujian.vercel.app/generals)。

## 功能

- **搜索**：中文、全拼、首字母（`zgl` → 诸葛亮）、称号、技能名，也能搜技能描述里的关键词（`思召剑` → 袁绍），并在卡片上显示命中的那句话。多个词用空格分隔，要同时命中。
- **筛选**：势力、体力上限、技能类型（锁定技、限定技、觉醒技、转换技、主公技……从技能描述中的加粗关键词自动识别）、武将/技能卡、可选主公。每个选项旁的数字会随其他筛选条件实时更新。
- **排序与视图**：按编号 / 拼音 / 体力 / 技能数排序；完整卡面或聚焦立绘；每行 3/4/5 张。
- **详情页**：每位武将一个预渲染的静态页面，内容包括卡面大图、势力、体力（含护甲）、编号、称号、画师，以及逐条技能。技能中的【牌名】、「标记」和加粗关键词会高亮显示。
- **关联**：同一武将的不同版本互相链接；技能卡（技能池、衍生武将）会挂在所属武将下。
- 筛选状态保存在网址里，可以直接分享；支持明暗主题；键盘操作：`Ctrl K` 或 `/` 搜索，回车打开第一个结果，详情页用 `←` `→` 翻页。
- **牌局记录**（`/session/`）：2–10 座位，每座只记身份与武将卡图（武将框支持中文/拼音查找）。座位按两行排布，8 人即 4×2。改动自动存在本机浏览器，可「复制分享链接」把整局编码进网址发给同桌，或「复制文字战报」。纯静态站没有后端，因此不做多人实时同步。
- 无框架、无构建工具、无外部请求。当前收录 349 张卡，整站约 86 MB，其中几乎都是图片。

## 使用

需要 Python 3.9+。

```bash
pip install -r requirements.txt
python build.py                          # 默认读取 ../characters 与 ../character2，生成到 ./site
python build.py --src ../characters ../character2 --out site
python -m http.server -d site 8000       # 本地预览 http://localhost:8000
```

之后新增或修改武将卡，重新运行 `build.py` 即可。未改动的图片会跳过，只重新生成页面；加 `--force` 可以重新编码全部图片。

### 输入格式

每张卡是一对同名文件，例如：

```
老UI.QUN004.率盟伐董.袁绍2.json
老UI.QUN004.率盟伐董.袁绍2.png
```

- 文件名格式：`模板.编号.称号.名字`。
- 名字末尾的数字（`袁绍2`）会被去掉，用于区分同一武将的多个版本。
- 名字里带 `技能卡` 或 `技能池` 的，会作为技能卡归到同编号的武将下。
- 名字前的版本前缀（界、谋、威、神、魔、族……）从文件名自动识别：`鸿谋翼远.谋鲁肃.json` 而 JSON 里名字是「鲁肃」，网站显示「谋鲁肃」，同名的不同版本仍会归到一起。图片名比 JSON 多前缀（`吴懿.json` + `谋吴懿.png`）也会自动配对。
- 可以传多个 `--src` 文件夹；文件名重复时，后面的文件夹覆盖前面的。

### 技能模拟器

`tools/` 里每个 `.html` 是一个独立的模拟器页面，在 `tools/tools.json` 里登记：

```json
{ "slug": "saran", "file": "saran.html", "name": "飒然", "title": "装备牌随机生成器",
  "desc": "一句话介绍", "skills": ["飒然"] }
```

- `skills` 里的技能名会自动匹配：拥有该技能的武将，其详情页技能旁会出现「▶ 模拟器」按钮，图鉴列表里也会带「模拟器」标记。留空则只出现在模拟器目录页。
- 构建时页面会原样发布到 `site/tools/<slug>/`，只在左上角加一个返回图鉴的按钮。

### 目录

```
build.py            生成脚本
overrides.json      按文件名给武将加显示前缀（威、谋、星……）
tools/              技能模拟器页面及 tools.json 登记表
templates/          页面模板（列表页、详情页、模拟器目录、牌局记录、404）
static/             样式与前端脚本，复制到 site/assets/
site/               生成结果，直接部署这个文件夹
```

## 部署

`site/` 是完整的静态网站，不需要服务器端程序。

- **GitHub Pages**：把 `site/` 一起提交，推送到 `main` 后，`.github/workflows/pages.yml` 会自动发布。需要先在仓库的 Settings → Pages 里把 Source 设为 GitHub Actions。
- **Vercel / Netlify / Cloudflare Pages**：把输出目录（Output / Publish directory）设为 `site`，构建命令留空。

原始 PNG 很大（每张约 2.4 MB），建议不要放进仓库，只提交生成后的 `site/`（WebP，约 86 MB）。
